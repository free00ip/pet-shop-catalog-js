# pet-shop-catalog-js

A simple pet shop catalog application built with JavaScript.

## 🌐 Live Demo

[View live demo](https://free00ip.github.io/pet-shop-catalog-js/)

## 📌 About the Project

A simple pet shop catalog that displays products and allows users to search for items by name.

The project was created to practice JavaScript fundamentals, including working with objects and arrays, filtering data, DOM manipulation, and rendering content using HTML templates.

## 🛠 Technologies

- HTML
- CSS
- JavaScript
- DOM Manipulation
- HTML Template Element
- Array Methods

## 👩‍💻 Features

- Display product cards from a JavaScript array
- Generate product cards using HTML templates
- Search products by title
- Case-insensitive search
- Clear previous search results before displaying new ones
- Display a "Nothing found" message when no matching products exist
